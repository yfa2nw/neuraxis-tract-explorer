## New features I added

- **3D View**: View pathways on a both the original 2D schematic alongside a new, dynamic 3D brain model showing where each cross-sectional slice and tract sits in space. Includes camera presets, zoom controls, dark mode support, and an opacity slider
- **Cross-Sectional Slice Modes**: Switch between vector diagrams (original), and the new Weigert stain, T1-weighted MRI, and Luxol Fast Blue views across all 11 levels
- **Slice Filtering and Zoom**: Selecting a tract or structure filters the view to only the slices where it appears. Click any slice to enlarge it, and see both decussation markers and direction indicators where pathways travel or cross the midline.
- **Quiz Mode**: Generate practice quizzes filtered by slice and question format (multiple choice, free-text typing with abbreviation support, or full slice labeling).
- **Customizable Layout and General UI Improvements**: Added a search bar for quick lookup (suggested by Jojo), light/dark mode toggle, and draggable panel borders to resize sections
